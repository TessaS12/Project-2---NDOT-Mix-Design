# Project-2 NDOT Mix Design
Code and research files for P2 - Automation of Concrete Mix Design

This project transforms the logic from the NDOT Concrete Mix Excel document to a Python workflow. The model will take sequential inputs from the user about the weights and specific gravities of materials in the mix, and then return a summary describing the weight of 1 cubic yard of that mix.
